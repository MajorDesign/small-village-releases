# Raízes do Vale: versões

Aqui ficam só os arquivos do jogo para instalar no celular (APK) e os pacotes de atualização. O código fica em um repositório privado.

## Como instalar

1. Abra a aba **Releases** e baixe o arquivo `.apk` da versão mais recente.
2. Abra o arquivo no celular e permita a instalação.
3. As atualizações seguintes são baixadas pelo próprio jogo ao abrir.
